# 导入约定

按子模块导入，路径尽量贴近 sklearn：

```python
from sklplus.linear_model import LogisticRegression, Ridge
from sklplus.ensemble import RandomForestClassifier, XGBClassifier
from sklplus.preprocessing import (
    StandardScaler,
    CleanColumnNames,
    RareCategoryGrouper,
    DateFeatureExtractor,
    TargetLabelEncoder,
)
from sklplus.sampling import SMOTE
from sklplus.anomaly import IForest
from sklplus.pipeline import Pipeline, ImbPipeline
from sklplus.compose import ColumnTransformer
```

再导出在能做到时与上游是同一对象，例如 `sklplus.ensemble.RandomForestClassifier is sklearn.ensemble.RandomForestClassifier`。

## Boosting 的两条 import 路径

`XGBClassifier` / `LGBMClassifier` / `CatBoostClassifier`（以及对应的 Regressor）同时出现在 `sklplus.ensemble` 与 `sklplus.xgboost` / `lightgbm` / `catboost`。同一个类对象：

```python
from sklplus.ensemble import XGBClassifier as A
from sklplus.xgboost import XGBClassifier as B
assert A is B
```

`LGBMClassifier` / `LGBMRegressor` 对应 `sklplus.lightgbm`；`CatBoostClassifier` / `CatBoostRegressor` 对应 `sklplus.catboost`。不是两套封装。

## `Pipeline` 与 `ImbPipeline`

两者都从 `sklplus.pipeline` 导入。

- 普通 `Pipeline` 仍是 sklearn 那份。
- 步骤里有 `fit_resample`（例如 `SMOTE`，或 `sklplus.sampling.RemoveOutliers`）时用 `ImbPipeline`（imblearn 的 pipeline）。

不要把只提供 `fit_resample`、没有按行过滤的 `transform` 的采样器塞进普通 sklearn `Pipeline`。

## 异常检测

`sklplus.anomaly` 下是对 pyod 的薄包装（`IForest`、`LOF` 等），以便放进 sklearn `Pipeline`。
