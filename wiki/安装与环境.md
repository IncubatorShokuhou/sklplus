# 安装与环境

包名、import、仓库名都是 **sklplus**（https://github.com/IncubatorShokuhou/sklplus）。

## 依赖

- Python `>=3.10`
- `scikit-learn>=1.3`
- 默认还会装：`numpy`、`pandas`、`scipy`、`joblib`、`xgboost`、`lightgbm`、`catboost`、`imbalanced-learn`、`pyod`、`kmodes`、`category-encoders`、`feature-engine`

许可证 MIT，见仓库 `LICENSE`。

## 安装

```bash
pip install sklplus
```

PyPI：https://pypi.org/project/sklplus/

克隆后可编辑安装（含测试工具）：

```bash
pip install -e ".[dev]"
```

`[dev]` 额外装 `pytest>=7` 和 `ruff`。
