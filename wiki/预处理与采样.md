# 预处理与采样

自写预处理在 `sklplus.preprocessing`，与再导出的 scaler / encoder 放在一起。采样器在 `sklplus.sampling`，不在 preprocessing。

下面只列 0.1.1 里相对 sklearn 再导出多出来的那几块。参数以源码为准，这里不另编 API。

## P0

### `CleanColumnNames`

期望输入是 pandas `DataFrame`。把列名里非 ASCII 字母数字 / 下划线的字符替换成 `_`（`[^0-9a-zA-Z_]`）。

### `RareCategoryGrouper`

期望 `DataFrame`。对 object / category / string 列，把相对频率低于 `min_frequency`（默认 `0.05`）的水平合并成 `replacement`（默认 `"rare"`）。

### `DateFeatureExtractor`

期望 `DataFrame`。从 datetime 列抽出日历特征（默认 `year` / `month` / `day` / `dayofweek`）。`drop_original=True`（默认）时丢掉原来的日期列。

### `TargetLabelEncoder`

分类标签的薄封装，内部是 sklearn `LabelEncoder`。按 `y` 使用：

```python
enc.fit(y)
yt = enc.transform(y)
y_hat = enc.inverse_transform(yt)
```

## P1

### `GroupFeatures`

按列组做行内聚合统计。需要非空的 `groups`：组名 → 列名列表。每个组、每种聚合会多一列 `{group}_{agg}`。允许的聚合名：`min` / `max` / `mean` / `std` / `median` / `mode`。默认 `aggregations` 是 `min, max, mean, std, median`（不含 `mode`）。`drop_original=False`（默认）时保留原列。

### `RemoveMulticollinearity`

去掉高相关数值特征。`threshold` 默认 `0.9`（Pearson 绝对值）。`prefer_target=True` 且 `fit` 时提供了数值 `y`：相关对里保留与 `y` 绝对相关更高的那个。

### `IterativeImputerPlus`

数值列用 sklearn `IterativeImputer`；类别列用众数（`SimpleImputer(strategy="most_frequent")`）。类别列不进入迭代数值模型；v0.1 不做「先序数编码再一起插补」。

### `TextEmbedder`

对文本列做 BoW（`CountVectorizer`）或 TF-IDF（`TfidfVectorizer`），再拼回表。`method` 为 `"bow"` 或 `"tfidf"`（默认）。这是表格文本列的向量化，不是 NLP 专题模块。

## 采样：`RemoveOutliers`

`sklplus.sampling.RemoveOutliers` 是 imblearn 风格采样器（`fit_resample`），只在训练集去掉异常行。请配合 `ImbPipeline`，让 `y` 同步过滤。

不要把它当普通 sklearn `Pipeline` 里的 transformer：没有用来过滤测试行的 `transform`（避免把「训练时丢行」误用到测试集）。

`method`：`"iforest"`（默认）、`"lof"`、`"ee"`（`EllipticEnvelope`）。`contamination` 默认 `0.05`。

`sklplus.sampling` 里其余多数是 imbalanced-learn 的再导出（如 `SMOTE`）。有 `fit_resample` 的步骤同样走 `ImbPipeline`。
